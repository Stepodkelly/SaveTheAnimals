# V1 Current Route Demo

V1 is the currently implemented `#save_the_animals` demo.

## Contract

V1 answers:

> Given a dated satellite-derived flood observation, a known ranger base and a reported incident location, what preliminary mapped-road access route is available?

## Implementation Location

The V1 app remains in the repository root:

```text
public/data/amboseli/
src/
server/
docs/
```

## Scope

- Satellite imagery map with traced flood polygons
- Small Amboseli road graph
- Before, during and recovery comparison toggles
- Deterministic routing with flooded-edge blocking
- Exa-powered evidence panel
- Gemini-assisted explanation when a valid server key is available
- Local Q&A for public, official, highly localized sources

## Non-Claims

- No confirmed safe rescue route
- No arbitrary off-road routing
- No individual animal detection
- No live satellite ingestion
